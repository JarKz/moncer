# Moncer — money tracer

The main intention of this project is tracking the income and the outcome to find causes of wasting the money.

All data stores like a log with transactions and because of it you can get a very flexible overview.

## Intention

The application doesn't aim to be featureful and provide a lot of ways to do. Instead it provides
a small amount commands to make a transaction. The goal is easiness to write an information, because
powerful systems requires much effort to open and setup.

You can just type something like

```bash
moncer add +350 salary
```

And forget about it! No need to open application, wait until it connects to server and find a way to write the same thing.
Also because of possibility to use in terminal, it's not hard to do it while you're doing another task.
